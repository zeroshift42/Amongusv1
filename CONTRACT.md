# Shared contract — NAVE 26

All shared imports use .js extensions. src/shared/world.ts owned by root exports WORLD {width,height}, ROOMS [{id,name,x,y,w,h,color}], FLOORS [{x,y,w,h}], TERMINALS [{id,room,x,y,kind}], VENTS [{id,x,y}], COLORS string[], walkable(x,y), lineOfSight(a,b), distance(a,b). World coords pixels.
Socket client emits request event with payload and ack {ok:boolean,error?:string,...data}. Events:
admin:create {password,settings?} -> {code,token,id}; admin:resume {code,token} -> {id}; join {code,name,color:number} -> {id,token}; resume {code,token} -> {id}.
admin {action:'start'|'pause'|'resume'|'end'|'reset'|'lock'|'unlock'|'kick'|'settings',id?,settings?}.
move {x:number,y:number} normalized direction [-1,1]; action {type:'kill'|'report'|'emergency'|'vent'|'sabotage'|'repair',target?:string,kind?:string}; vote {target:string|null}; chat {phrase:number,target?:string,room?:string}; task:start {id:terminalId} -> {challenge:{id,kind,seed,step,startedAt,...}}; task:input {id,action:any} -> {challenge?,complete?:boolean}.
Server emits state at 10Hz, object {code,phase:'lobby'|'playing'|'meeting'|'ended',paused,locked,settings,me:id,players:[{id,name,color,x,y,alive,connected,role?:'crew'|'impostor',vented?:boolean}],bodies:[{id,x,y,color}],tasks:[{id,done}],progress:{done,total},sabotage:null|{kind,remaining,panels:string[]},meeting:null|{remaining,stage:'discussion'|'voting',votes:number,eligible:number,messages:[{name,text}],voted?:boolean},winner?:string,reason?:string,remaining:number,killCooldown:number,notice?:string}. Student snapshots only visible players and own secret role/tasks; lobby/meeting players roster public without locations leaking. Admin snapshot all roles, player tasks optional, admin flag true. Client renders hidden player disappear. state.tasks own assigned terminal IDs. Server handles time in seconds simulation; paused freezes everything. Server exports createGameServer({adminPassword,port?}) for tests returns {http,io,rooms,listen(port=0):Promise<number>,close():Promise<void>}; room model may be accessed only by tests for setup.
Task protocol detail agreed: challenge seed array numbers, step number. For cable task send action {value:n} in seed order (matching pair n). Other kinds use actions as documented by server; client agent coordinate with server agent directly. All action completion validated server (distance, role, assigned task, correct seed/order + timing). No client completion event.
