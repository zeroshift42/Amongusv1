# Recursos y atribuciones

Los astronautas, símbolos, nave, decoraciones, fondos y sonidos simples de esta aplicación se construyen mediante código propio (SVG, primitivas Canvas/Phaser y Web Audio). No se distribuyen archivos gráficos, audio, mapas, marcas ni tipografías extraídos de Among Us. NAVE 26 es un proyecto independiente, sin afiliación con Innersloth.

Dependencias de ejecución: Phaser, Express, Socket.IO y socket.io-client. Sus versiones resueltas están fijadas en `package-lock.json`; cada paquete conserva su licencia y avisos en la distribución oficial instalada por npm. Las herramientas TypeScript, Vite, tsx y Prettier se usan durante desarrollo/compilación. Revisar las licencias de las dependencias antes de redistribuir un producto comercial.

El proyecto no carga recursos desde CDNs de terceros durante las partidas ni necesita llamadas a APIs de inteligencia artificial.
